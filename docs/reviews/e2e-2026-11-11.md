# Automated end-to-end run — 2026-11-11

Scope: the real release binaries, a fresh SQLite database, the bundled sample
knowledge base, the built `frontend/dist` bundle, and headless Chromium. This
supersedes the "browser checks not performed" note in
`docs/reviews/e2e-api-2026-11-11.md`; both suites now run from one command.

## Command

```bash
PORT=8099 OUT=/tmp/opencode/hnswhy-e2e-final3 scripts/e2e/run.sh
```

The script starts `build/backend/hnswhy_server` on a fresh database, waits for
`/api/health`, runs `scripts/e2e/api-e2e.sh`, runs `scripts/e2e/ui-e2e.cjs`,
and stops the server. Raw output is in `docs/results/e2e/run-2026-11-11.log`; the four screenshots
are in `docs/results/e2e/`.
